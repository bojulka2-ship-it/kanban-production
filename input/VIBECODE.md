1. **Один этап = один промпт → проверка по чек-листу → коммит → следующий этап.** Не переходите дальше, пока текущий не работает.
2. Промпты копировать целиком из блоков кода. Вставлять в OpenCode, открытый в папке проекта `D:\123Free\les7_kanban-production`.

4. Если этап не прошёл с первого раза — коммитить только после успешной проверки.
