## 6. Дизайн (брендбук)

Оформление на исполнителе. Стиль: чистый рабочий минимализм, доска читается с расстояния.

**Цвета:**
| Назначение | HEX |
|---|---|
| Акцент (кнопки, активная карточка, ссылки) | `#2563EB` |
| Hover акцента | `#1D4ED8` |
| Фон страницы | `#F1F5F9` |
| Карточки, модалки | `#FFFFFF` |
| Текст основной / вторичный | `#0F172A` / `#64748B` |
| Границы | `#E2E8F0` |
| Завершено | `#16A34A` |
| Дедлайн ≤ 3 дней | `#F59E0B` |
| Просрочка, отмена, ошибки | `#DC2626` |
| Карточка «Ожидание» | `#CBD5E1` |

**Типографика:** Inter (400/500/600/700, кириллица). Базовый размер 14px, заголовки 16/20/24, табличные данные 13px.

**Компоненты:** радиусы 8px (карточки) / 12px (модалки), мягкие тени, отступы кратны 4px, empty states с подсказкой действия.
